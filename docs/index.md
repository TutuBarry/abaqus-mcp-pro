# Abaqus MCP Pro

Professional MCP server suite for Abaqus/CAE — 100+ tools, dual transport, capsule tracking, physics contracts, and skills integration.

## What is Abaqus MCP Pro?

Abaqus MCP Pro connects AI clients (Codex, Claude, etc.) to a running Abaqus/CAE session through the Model Context Protocol (MCP). You describe what you want, and the AI executes it directly in Abaqus.

## Key Features

- **TCP socket bridge** — 10-50ms latency
- **100+ tools** — Full Abaqus automation
- **AST error diagnostics** — Auto-fix suggestions
- **Dual transport** — TCP + file IPC
- **Capsule tracking** — Experiment state snapshots
- **Physics contracts** — Automated validation
- **Skills knowledge base** — 20+ CAE skill definitions
