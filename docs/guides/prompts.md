# Prompts

Abaqus MCP Pro provides 13 guided workflow prompts. Use these as starting points for common analysis tasks.

## Available Prompts

| Prompt | Description |
|--------|-------------|
| `setup_static_analysis` | General static stress analysis workflow |
| `setup_contact_analysis` | Contact analysis with surface interactions |
| `setup_modal_analysis` | Natural frequency and mode shape extraction |
| `setup_thermal_analysis` | Heat transfer and thermal stress |
| `setup_dynamic_analysis` | Dynamic response analysis |
| `setup_coupled_analysis` | Coupled field analysis |
| `setup_fatigue_analysis` | Fatigue life prediction |
| `setup_optimization` | Design optimization workflow |
| `define_material` | Material definition wizard |
| `setup_mesh` | Meshing strategy guide |
| `extract_odb_results` | ODB post-processing workflow |
| `debug_job` | Job debugging and troubleshooting |
| `session_workflow` | General session orientation |

## Usage

Ask your AI client to use a specific prompt:

> "Use the setup_static_analysis prompt to set up a cantilever beam analysis"

The prompt will guide the AI through the complete workflow, asking for necessary inputs and executing each step.
