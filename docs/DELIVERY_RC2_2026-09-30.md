# 1.1.0rc2 开发与验收

本轮交付包含切帧性能改造、真实 CAE 菜单联调、摩擦/弹塑性接触验证、任务历史及参数对比报告。此文件记录源码功能，发行物安装结果见 `VALIDATION_RC2_2026-09-30.json` 和工作区 `audit-artifacts/release-rc2/`。

## 查看器

- 缓存解析后的坐标、拓扑及全部节点场，切换变量不再重新解析 XML；LRU 最多 4 帧，估算保留数据上限 96 MiB。此限制不包含临时 XML、场景和 GPU 内存。
- 相同拓扑复用 Three.js 网格及位置/颜色缓冲区；变形从原始坐标重新计算，不累积上帧位移。
- 预取一个相邻帧；切换结果或快速拖动取消无关读取。过期请求不能恢复旧结果。
- 快速切帧不显示加载遮罩，慢读取延迟显示非阻塞提示，保留当前画面。失败后恢复当前显示帧/字段的选择。
- ODB 面板增加结果任务历史；成功任务可重新打开，失败任务可读取末尾 16 KiB 日志。接口仍需要本机会话认证。

三档真实曲面 ODB 最后帧，使用实际 VTU 解析器与 Three.js 缓冲区构造器进行 Node CPU 测量。最终构建对应的复测中，16,758 节点首次读取/解析/构造共约 144 ms，缓存后更新中位数约 8.6 ms（5 次）。该对照是本轮冷/热路径测量，不是跨版本完整动画 FPS 对比；不包含浏览器 HTTP、GPU 上传及绘制。

完整 ASCII 解析与场景构造的合成压力测试覆盖 1 万、10 万、100 万节点。百万节点解析约 575 ms、缓冲区更新约 116 ms、采样进程 RSS 约 400 MB。数据为不连接的六面体，不能替代百万节点真实求解或浏览器 GPU 验收。

另对 124,138 节点、114,688 个 C3D8R 单元的三维接触模型进行了真实尝试。两线程运行达到 600 秒预算时，分析仅推进到步时间 0.07，已停止任务树并保留未完成结果，未导出为成功查看结果。这项大实体接触性能验收仍不通过，不能以杆件或合成数据替代。

## 真实大规模杆件验证

`benchmark_large_rod.py` 使用连续 T3D2 轴向杆，L=100 mm、A=10 mm²、E=210000 MPa、F=1000 N，理论端位移 0.04761905 mm。输出两个 U 场帧，所有规模均完成真实求解、位移/反力检查和导出。

| 节点数 | 求解 s | 导出 s | 最后帧冷路径 CPU ms | 缓存更新中位数 ms |
|---:|---:|---:|---:|---:|
| 10,001 | 17.22 | 2.04 | 26.3 | 3.7 |
| 100,001 | 23.63 | 20.99 | 186.1 | 28.7 |
| 1,000,001 | 97.54 | 233.92 | 2744.7 | 247.6 |

百万单元杆的原生端位移 0.04761806 mm、反力 -999.97595 N；两个 VTU 合计约 341 MB。解析帧缓存保留约 53 MB，测量进程当时 RSS 约 805 MB，RSS 为采样值而非严格峰值。杆/梁线段使用索引缓冲区并复用。该例验证百万节点线单元的数值与 CPU 路径，不代表百万节点实体接触、全应力场或浏览器帧率通过。

## 接触工程验证

新增生成参数：`--curved --friction 0.2 --slide 0.5`、`--curved --plastic`。材料为演示性材料，未标定。摩擦采用有限滑移和显式 DIRECT 法向约束；弹塑性使用 E=1000 MPa、屈服 5 MPa、塑性应变 0.1 时应力 8 MPa 的硬化表。

首次摩擦运行虽然求解完成，但 COPEN 最小约 -0.00707 mm，未通过既定 -1e-4 mm 穿透门槛。改用 DIRECT 后重新求解，COPEN 最小约 -6.55e-8 mm，通过原门槛，未放宽验收标准。原失败证据保留在 `rc2-contact/`，最终结果在 `rc2-contact-direct/`。

| 新场景 | 总反力 N | 额外验证 | 结果 |
|---|---:|---|---|
| 摩擦滑移 | 379.056 | ALLFD=33.402 N·mm，力平衡及穿透检查 | 通过 |
| 弹塑性压入 | 218.061 | 最大 PEEQ=0.04924，ALLPD=9.520 N·mm | 通过 |

既有六次网格结果新增原生压力分布、投影接触面积估计、压力积分力及峰值变化记录。面积采用未变形表面节点分摊面积、按正压力阈值选取，是离散估计，不是精确接触边界。

| 原场景最后两级相对变化 | 总反力 | 面积估计 | 峰值 CPRESS | 积分点峰值 Mises |
|---|---:|---:|---:|---:|
| 平面 | 0.58% | 约 0% | 12.67% | 9.29% |
| 曲面 | 1.71% | 12.54% | 3.35% | 2.87% |

按每个指标独立的 5% 阈值，平面峰值与曲面面积估计仍未收敛。报告明确保留这些不通过项。查看器应力仍是元素节点等贡献平均、先计算不变量，可能跨区域；原生积分点峰值不应与平均云图峰值直接等同。

## CAE 与浏览器

实际打开 Abaqus/CAE 2026，观察 Plug-ins → ABAQUS MCP Pro → Start MCP Bridge。通过 GUI 主线程桥接提交杆件作业、查询 COMPLETED、打开/查询/关闭 ODB、执行 6×7。随后从菜单 Stop MCP Bridge 停止，验证端口关闭。证据：`rc2-gui-session/report.json` 及真实作业输出。验收脚本已修正 `return_value` 信封读取，并支持恢复既有作业验证。

发现旧文件 `abaqus_mcp_gui_plugin.py` 与现行文件重复注册菜单。安装器只对具有本项目特征的旧文件追加 `.disabled-<timestamp>` 备份后缀；保留原内容。陌生同名文件不自动处理。

浏览器连接仍返回 `nodeRepl.fetch request failed`。原生 Edge 状态读取被自动审批检查拒绝，原因是无法可靠识别当前网址。本轮已停止浏览器界面操作，因此浏览器目视、交互矩阵与 GPU 指标均未验收；CAE 的通过记录不能替代它们。

## 项目和报告

新增 MCP 工具 `list_project_runs(output_root)`、`compare_project_runs(run_paths, output_dir)`，注册面为 138 工具、13 提示词、74 资源。新增命令：

```bash
abaqus-mcp-pro-project history runs
abaqus-mcp-pro-project compare runs/<run-id> --output reports/scan
abaqus-mcp-pro-project compare runs/<run-a> runs/<run-b> --output reports/comparison
```

输出 JSON、CSV、独立 HTML，保留参数、KPI 选择条件、状态、证据目录、输入与 ODB 哈希。单位不同会拒绝比较；选择条件不同会分组；失败/仅准备项不进入比较基准；零基准不计算百分比。已用真实三点载荷扫描生成 9 行指标报告。清单可增加 `project` 名称，运行记录会保留。

## 回归、依赖与剩余范围

391 项 Python、43 项前端测试通过，Pyflakes 通过。前端构建工具升级至 Vite 7.3.6，Node 需要 20.19+ 或 22.12+；本机 npm audit 报告 0 项已知漏洞。锁文件同步提交到工作区。

本机只有 Abaqus 2026，其他 Abaqus 版本、其他操作系统的真实求解未验收。远程 CI 和公开发布尚未执行。CI 配置扩展 Windows/Linux Python 测试，不应视为远程运行已经通过。

后续应集中于实际浏览器/GPU验收、接触面积与边缘峰值的进一步收敛，以及减少逐帧 ASCII 重复几何的导出体积。当前缓存和缓冲区复用不减少初次 ODB 导出耗时。
