# 结果查看与分享流程

状态：2026-10-13 确认的开发方向。本文区分现有能力与待实现能力，不表示通用云发布功能已经交付。

## 统一流程

**ODB → 轻量化导出 → 本地预检 → 按需发布妙搭 → 分享链接**

本地 Abaqus 负责读取 ODB、提取网格和场变量；同一套浏览器查看器负责本地与云端三维展示；妙搭负责托管页面和结果文件。云端查看不依赖分享者电脑持续在线，也不要求接收者安装 Abaqus。

本地导出与预检保留。本地打开页面作为可选操作；仅查看或处理保密项目时，流程在本地结束。普通求解、导出和预检不应自动上传数据。用户明确要求发布或分享时，才进入指定云平台流程。

## 现有实现

- `open_result_viewer` 与 `viewer_bridge.publish_result` 可为本机 ODB 发起导出并返回对应任务的本地查看链接；后者的 `publish_result` 名称目前不表示云发布。
- VTU 导出及查看器支持网格、场变量、图例、切帧和变形显示，具体字段取决于 ODB 输出与导出选择。
- 已针对单个实际结果手工完成压缩、上传飞书文件存储、部署妙搭页面及线上显示验证。该案例尚未形成仓库内的通用发布接口。
- 本次妙搭页面部署成功，但对外分享被应用的“【数字】L3 对内公开”密级限制；部署成功与外部可访问必须分别记录。
- 本次文件使用 30 天签名链接。页面地址的存续不代表数据链接永久有效，必须独立记录到期时间。

## 分阶段开发

### 1. 可复用轻量化分享包与本地预检

复用导出结果，生成由查看器代码、压缩帧和分享清单组成的静态包，不重新计算。清单记录源 ODB 摘要、导出器版本、分析步、帧选择、字段、单位、截面点、平均方式、文件大小及内容摘要。缓存命中必须同时匹配源内容与导出选择，不能只比较文件名。

预检分为两层：

- 数据检查：元数据可解析、帧文件齐全、压缩可解码、摘要匹配、网格连接与字段长度有效、缺失值与范围可解释；单位未知时明确显示未知。
- 浏览器检查：选定的首末帧可加载、模型可见、图例与字段匹配、切帧和总位移可用（源数据存在 U 时）；未完成浏览器验证必须单独标记。

预检检查展示和交付完整性，不替代求解收敛、材料合理性或工程验收。分享元数据移除本机绝对路径、本地访问令牌和无关任务信息；原始 ODB 不进入默认分享包。

### 2. 妙搭发布适配器

以同一静态包为输入，上传结果文件，提交查看器代码，发布并查询最终状态。发布失败可恢复；重试前核对已有应用、文件摘要和发布记录，避免反复创建副本。

返回页面链接、部署状态、实际访问范围、数据到期时间和验证结论。分别表达：未发布、发布中、发布失败、已部署但受限、已部署且目标访问验证通过。登录后的创建者能够打开页面，不能作为匿名访问验证。

发布目标范围由用户的分享要求确定。遇到组织策略、密级或权限限制时保留发布结果并说明阻塞原因，不自动修改密级或绕过组织限制。

### 3. MCP 编排与维护

增加统一的结果准备/预检入口，以及独立的按需发布入口；工具名称和参数在实现时确定，未注册前不列入可用工具清单。保留本地查看能力，统一复用查看器源码，避免每个结果复制后长期独立维护。

保存发布记录，支持手动刷新数据签名并更新现有页面。自动续期或定期检查仅在用户明确要求后配置；不得把需要续期的链接称为永久链接。

## 交付完成条件

本地模式：导出完成，预检结果与本地查看入口可查。

云端模式：上述本地条件通过，最新代码已部署，实际访问范围符合分享要求，结果数据与目标访问方式验证通过，到期时间明确。任何一项未满足都应返回具体未完成项，而不是只返回一个 URL 并宣称分享成功。
